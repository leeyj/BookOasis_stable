# 🐛 알라딘 플러그인 API 호출 상세 디버그 로깅 추가

## 1. 개선 내역 및 요청 사항
- **요청 사항**: 알라딘 메타데이터 수동 매칭 시 검색 실패 원인을 명확히 파악할 수 있도록 플러그인 내부의 API 호출 및 키 조회 단계에 상세 디버그 로그 추가.

## 2. 영향도
- **영향 범위**: 알라딘 메타데이터 플러그인 내부 실행 흐름 (`_get_ttbkey`, `search` 메서드)
- **우선순위**: 보통 (디버깅 용이성 개선)

## 3. 변경 상세 내용
- **수정 소스 파일**: `plugins/metadata/aladin.py`
- **조치 내용**:
  1. **TTBKey 조회 로깅**: 플러그인 전용 설정, 레거시 설정, `.env` 파일 각각의 획득 여부를 콘솔에 출력하고, 획득한 키는 앞 4자리를 제외하고 마스킹(`****`) 처리하여 보안을 확보하였습니다.
  2. **API 요청 URL 로깅**: 상품 검색(ItemSearch) API 호출 직전의 파라미터가 포함된 URL을 마스킹하여 로깅하도록 추가하였습니다.
  3. **응답 데이터 로깅**: API HTTP 응답 코드 및 수신받은 JSON 원문 바디를 그대로 콘솔에 출력하여 파싱 이전 응답 오류나 정상 응답 여부를 모니터링할 수 있도록 조치하였습니다.
  4. **예외 트레이스백 로깅**: API 호출 중 네트워크 예외 등이 발생했을 때 단순 에러 메시지 외에 `traceback.format_exc()`를 활용해 스택 트레이스 전체가 출력되도록 개선하였습니다.

## 4. 해결 사항 및 검증 결과
- 수정 후 `deploy.py`를 통해 원격 배포 및 재구동을 진행하였고, 사용자가 메타데이터 검색 시도를 수행하며 서버 콘솔 로그를 확인하기로 조치 완료하였습니다.
