# 🐛 환경설정 플러그인 탭 비어남 및 태그 불일치 버그 조치

## 1. 버그 내역 및 증상
- **증상**: 환경설정 페이지 진입 시 스캔 스케줄 테이블 및 플러그인 설정 목록 전체가 로드되지 않고 아래 콘텐츠 영역이 텅 빈 화면으로 노출되는 레이아웃 붕괴 장애가 발생함.
- **콘솔 로그**: 자바스크립트 실행 오류(Exception) 및 API 호출 실패 에러가 콘솔에 찍히지 않은 채 조용히 숨겨진 현상.

## 2. 영향도
- **영향 범위**: 관리자용 환경설정 페이지 (스케줄 관리 및 알라딘 OpenAPI 설정 변경 불가)
- **우선순위**: 중

## 3. 원인 분석
- `templates/components/tab_media_library.html` 파일 내부의 `<!-- 2. 일반 설정 탭 -->` 영역 구조 분석 결과, `settings-tab-general`의 시작 `div` 태그에 대한 닫는 `</div>` 태그가 1개 누락되어 짝이 맞지 않음이 식별됨.
- 이로 인해 바로 아래 위치한 형제 노드여야 할 `<!-- 3. 플러그인 설정 탭 -->` (`settings-tab-plugins`) 영역이 일반 설정 탭 내부의 **자식 노드(중첩 구조)**로 잘못 렌더링됨.
- 일반 설정 탭이 초기 `display: none` 상태이므로 자식인 플러그인 설정 탭 영역도 `display: flex`가 켜져도 물리적으로 상위의 `none`에 갇혀 노출되지 않았던 것임.

## 4. 조치 사항
- **수정 소스 파일**: 
  - `templates/components/tab_media_library.html` (일반 설정 탭 닫기 </div> 추가)
  - `static/js/book_list.js` (불필요한 `sort_helper.js` 404 임포트 코드 소거)
  - `deploy.py` (원격지에 남아있는 레거시 구형 `aladin.js` 및 `aladin_search.js` 삭제 로직 결합)
- **조치 내용**:
  - `tab_media_library.html` 276라인 하단에 닫는 `</div>` 태그를 추가하여 `settings-tab-general`의 중첩 꼬임을 수정하였습니다.
  - `book_list.js` 에서 404 에러를 남기던 무의미한 동적 임포트 부분을 삭제하였습니다.
  - 배포 스크립트를 확장해, 원격지 서버 `static/js/` 하위에 잔존하는 구식 미사용 스크립트 파일을 안전하게 소거 조치하였습니다.

## 5. 해결 사항 및 검증 결과
- 배포 및 재시작 후 브라우저 E2E 검증을 진행했습니다.
- `환경설정 -> 플러그인 설정` 탭에 진입 시 '알라딘 도서 검색' 폼 필드와 TTBKey 입력 텍스트 박스, '설정 저장' 버튼이 완벽하게 화면에 출력되는 것을 확인하였습니다.
- 더불어 콘솔 창에 찍히던 `sort_helper.js` 404 에러 경고도 말끔히 사라졌습니다.
