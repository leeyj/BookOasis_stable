# 🐛 설정 탭 스케줄 관리 버튼 줄바꿈 현상 개선

## 1. 버그 내역
- **현상**: 환경설정 탭 내의 '스케줄 관리' 테이블 제어 버튼("저장", "스캔", "강제스캔")의 너비가 협소해 텍스트가 강제로 줄바꿈(예: '저\n장', '스\n캔')되어 레이아웃이 미관상 깨져 보임.
- **원인**: 각 제어 버튼 엘리먼트 내에 줄바꿈 방지 스타일이 누락되어 반응형 혹은 패딩 한계 시 글자가 아래로 밀려남.

## 2. 영향도
- 기능 동작에는 영향이 없으나, UI 시각적 레이아웃이 뭉개져 보여 미디어 서버의 전반적인 사용자 인터페이스 미관(UX 품질)을 해침.

## 3. 수정 사항
- **대상 파일**: [static/js/scheduler.js](file:///c:/project/media_server/static/js/scheduler.js#L59-L61)
- **조치 내용**:
  - 스케줄 제어 세 가지 버튼("저장", "스캔", "강제스캔")의 인라인 `style` 속성에 **`white-space: nowrap;`** 구문을 추가하여 버튼 내부의 텍스트가 절대 개행되지 않도록 설정함.

## 4. 해결 사항
- 스타일 적용 이후 화면 배율 및 뷰포트 크기에 상관없이 버튼 내부 텍스트가 강제로 줄바꿈되지 않고 한 줄로 명확하게 표시됨을 확인함.
