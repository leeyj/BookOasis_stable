# 🐛 PDF 뷰어 화면 크기 불일치 및 전환 오작동 개선

## 1. 버그/개선 내역
- **현상**: PDF 뷰어를 열어 도서를 볼 때 화면 해상도에 상관없이 1.5배 고정 스케일로 출력되어 화면 범위를 초과해 짤리거나 이상 크기로 표시됨. 또한, 페이지를 빠르게 넘기려고 시도하면 중간 요청들이 무시되고 클릭이 씹히는 전환 불통 현상이 빈번함.
- **원인**:
  - `viewer_pdf.js` 내에 뷰포트 스케일이 `scale: 1.5`로 하드코딩되어 모던 가변 스케일링이 작동하지 못함.
  - 드로잉 상태 플래그(`pdfIsRendering = true`) 락 구조로 인해 이전 드로잉 연산(무거운 PDF.js 렌더링)이 진행되는 도중 유입되는 다음 페이지 요청이 모조리 즉각 반환(`return`) 처리되어 씹힘.

## 2. 영향 범위
- PDF 통합 뷰어 모듈 (`static/js/viewer_pdf.js`)

## 3. 수정 사항
- **JS 수정** (`static/js/viewer_pdf.js`):
  - **가변 스케일링 엔진 신설**: 렌더링 부모 엘리먼트(`pdf-render-area`)의 실시간 크기를 측정하고, PDF 원본 가로/세로 비율에 대조하여 화면에 꼭 맞는 최적 비율(`scale = Math.min(scaleX, scaleY)`)을 동적으로 계산하여 적용함.
  - **렌더 태스크 취소 기능 주입**: 현재 렌더링 중인 작업 객체(`currentRenderTask`)를 추적하고, 새로운 페이지 요청 시 이전 `currentRenderTask.cancel()`을 명시적으로 실행하여 대기 락 없이 언제나 최신 탭을 즉각 그리도록 구조를 전면 개선함.

## 4. 해결 사항
- 모바일, 태블릿, PC 등 다양한 기기 및 브라우저 창 크기에 맞춰 상하좌우 잘림 없이 PDF 파일이 화면 중앙에 완벽히 피팅되도록 스케일링을 제공함.
- 사용자가 빠르게 책장을 넘기더라도 드로잉 락이나 클릭 씹힘 병목 현상 없이 실시간 즉각적인 페이지 이동 반응 속도를 구현함.
