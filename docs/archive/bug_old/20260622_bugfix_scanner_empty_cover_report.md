# 🐛 스캐너 0바이트 표지 추출 예방 및 스캔 리포트 연동

## 1. 버그/개선 내역
- **현상**: 스캐너가 백그라운드 구동될 때, VFS 원격 드라이브 경로의 순간적 끊김이나 I/O 에러 등으로 인해 표지가 0바이트 크기의 빈 파일로 부실 추출되어 저장되는 경우가 발생함.
- **원인**: 추출 완료 시 생성된 이미지 파일의 물리 크기 검증이 부재하여, 0바이트 쓰레기 파일이 디스크에 방치되고 DB에는 정상 추출된 것처럼 잘못 기록되어 관리되지 못함.

## 2. 영향 범위
- 스캐너 파일 동기화 프로세스 (`tools/scanner/core.py`)

## 3. 수정 사항
- **스캐너 코어 수정** (`tools/scanner/core.py`):
  - `process_folder_task` 내에서 `cover_image`가 생성된 후 `os.path.getsize()`를 이용하여 물리 파일 크기가 0바이트인지 검증하는 방어 코드를 신설함.
  - 0바이트 감지 시, 해당 빈 파일 캐시를 디스크에서 즉각 삭제 처리함.
  - `cover_image`의 상태값을 `None`으로 소거(무효화)함으로써 DB에 0바이트 이미지 썸네일 매핑이 들어가는 것을 차단함.
  - 표지 미확보 에러인 `NoCover` 항목으로 스캔 에러 리스트(`errors`)에 자동 편입시켜 환경설정 리포트에 `'추출 결과가 0바이트(빈 파일)입니다.'`라고 정밀하게 기록되도록 구현함.

## 4. 해결 사항
- 0바이트 비정상 표지가 디스크 및 DB에 반영되어 방치되는 현상을 사전 원천 차단함.
- 에러 리포트 데이터에 원인을 정확하게 명시하여, 운영자가 문제 도서를 한눈에 파악하고 즉시 조치(재스캔 등)할 수 있는 가시성을 확보함.
