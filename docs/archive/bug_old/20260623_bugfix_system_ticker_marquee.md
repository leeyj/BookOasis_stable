# 버그 내역
스캔 등 백그라운드 작업 수행 시 하단에 노출되는 '시스템 속보' 텍스트(마키 애니메이션)가 우측 화면 끝에서부터 시작하지 않고 화면 중간(좌측 기준 0)에서 시작하는 현상. 또한 텍스트가 지나가는 속도가 너무 빠르다는 사용자 피드백 접수.

# 원인
`style.css`에 정의된 `.ticker-content` 요소가 `position: absolute;`로 지정되어 있었으며, 텍스트가 지나가는 공간 확보를 위해 `padding-right: 100%;`가 적용되어 있었음. 하지만 이렇게 되면 `translate3d(0, 0, 0)`일 때 요소의 왼쪽 끝이 부모 요소의 왼쪽 끝에 맞춰지게 되어 텍스트 자체가 화면 좌측에서부터 노출된 채로 애니메이션이 시작됨.

# 수정 사항
1. `c:\project\media_server\static\css\style.css` 수정
   - `.ticker-content`의 `padding-right: 100%;` 속성을 제거하고 `padding-left: 100%;`로 변경. 이렇게 하면 `translate3d(0, 0, 0)` 상태일 때 화면 너비(100%)만큼 공간을 띄운 뒤 텍스트가 위치하게 되어 우측 화면 끝 밖에서 시작하게 됨.
   - 애니메이션 주기를 기존 `25s`에서 `40s`로 상향 조정하여 텍스트가 천천히 읽기 편한 속도로 지나가도록 수정.

# 해결 사항
- 이제 시스템 속보 알림이 자연스럽게 우측 끝에서부터 등장하여 왼쪽으로 흘러가며, 스크롤 속도도 눈에 띄게 완화됨.
