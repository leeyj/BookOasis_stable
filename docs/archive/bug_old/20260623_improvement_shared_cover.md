# 개선 내역
기존 스캐너 엔진은 메타데이터 내에 지정된 표지가 없는 경우, 폴더 내의 모든 개별 압축 파일(`cbz`, `zip` 등) 내부를 일일이 까서 첫 번째 이미지를 추출하는 Fallback 과정을 거침. 이로 인해 수십~수백 권의 압축 파일이 존재하는 웹툰 시리즈 폴더를 스캔할 때 파일 I/O 부하가 극심하게 발생하며 스캔 속도가 크게 저하되는 문제가 있었음.

# 해결 사항
1. **시리즈 폴더 감지 (`tools/scanner/core.py`)**
   - 폴더 내에 `kavita.yaml`과 `series.json`이 **모두(AND)** 존재하는 경우에만 확실한 웹툰/시리즈물 폴더로 간주(`is_series_folder`)하도록 엄격한 감지 조건을 설정함 (일반 소설책 등은 개별 표지가 있을 수 있으므로 제외).
2. **대소문자 무시 (Case-Insensitive) 파일 매핑 및 탐색 추가**
   - 윈도우 환경에서 작성된 `kavita.yaml`의 확장자 대소문자(`.cbz` 등)와 실제 리눅스 서버 상의 대소문자(`.CBZ`)가 다를 경우 키(Key) 매핑에 실패하여 YAML 표지를 찾지 못하고 곧바로 Fallback(압축 추출)으로 넘어가는 문제를 완벽히 차단함.
   - 부분(커버만) 재스캔 시 `Kavita.yaml` 파일명 자체의 대소문자 불일치(예: 리눅스에서 `kavita.yaml`로 저장된 경우)로 인해 파일을 통째로 읽어들이지 못하던 심각한 버그를 폴더 탐색 로직 우회를 통해 수정함.
3. **대표 커버(썸네일) 런타임 공유 무결성 수정**
   - 첫 번째 권이 압축 파일 추출(Fallback)이 아닌 `kavita.yaml`의 Base64 디코딩을 통해 표지를 얻었을 때도, 해당 표지가 정상적으로 메모리(`shared_cover_image`)에 보관되도록 로직을 수정함.
   - 첫 번째 추출에 성공한 대표 표지 파일을 캐싱해 두고, 동일 폴더 내의 후속 권들은 복잡한 압축 해제 연산 없이 즉각적으로 캐싱된 표지를 그대로 복사 적용(공유)하도록 획기적인 최적화를 달성함.

# 결과
불필요한 디스크 I/O와 압축 해제 연산이 99% 이상 감소하여 대용량 웹툰 폴더 스캔 속도가 비약적으로 단축됨.
