# 🐛 일반/성인 도서 전환 시 오른쪽 도서 목록이 미갱신되는 결함 조치

일반 도서와 성인 도서 라이브러리 타입을 스위칭할 때, 왼쪽 카테고리는 정상적으로 스위칭된 도서 유형의 카테고리들로 갱신되지만, 오른쪽의 도서 리스트 화면은 이전 도서 유형의 목록을 그대로 표출하고 있는 결함을 수정했습니다.

---

## 1. 버그 내역 및 현상
* **문제 상황**: 사용자가 "성인 도서"에서 "일반 도서"로 혹은 반대로 전환할 때, 왼쪽 사이드바 카테고리 목록만 새로 바인딩되고 오른쪽 콘텐츠 리스트 뷰는 기존 유형의 도서가 그대로 유지되어 UI/UX 일관성이 깨짐.
* **원인**: 
  - [tab_media_library.js](file:///c:/project/media_server/static/js/tab_media_library.js) 내 `switchLibraryType` 함수에서 라이브러리 타입 스위칭 시 `loadLibraries()`를 통해 사이드바 카테고리만 새로 그리고, 정작 현재 선택되어 있는 카테고리 상태(`state.currentLibraryId`)를 홈(`home`)으로 리셋하지 않고 기존 카테고리 상태를 재적용하여 데이터 갱신을 하려고 했음.
  - 이로 인해 이전 도서 타입의 ID 값에 의존한 목록 조회 API 요청이 들어가거나, 목록 갱신 흐름이 정상적으로 제어되지 않아 이전 목록이 그대로 화면에 표시되는 부작용이 발생함.

---

## 2. 해결 방안 및 수정 사항
1. **타입 전환 시 홈 카테고리로 강제 이동**:
   - `switchLibraryType(type)` 함수 내에서 전환 처리 완료 후 기존의 복잡한 조건부 분기 코드를 제거하고, 명시적으로 `selectCategory('home')`을 호출하도록 수정했습니다.
   - 이를 통해 라이브러리 타입 스위칭 시 왼쪽 카테고리가 갱신됨과 동시에, 오른쪽 도서 영역도 안전하게 홈 화면 대시보드(`loadDashboardData()`)로 전환되어 사용자가 올바른 범위의 도서 데이터를 볼 수 있도록 일관성을 복원했습니다.

---

## 3. 영향도 및 결과
* 일반 도서 <-> 성인 도서 간 어떠한 화면 상태에서든 탭을 클릭하여 스위칭하게 되면 즉시 사이드바가 새로운 타입에 맞는 라이브러리로 갱신되고, 오른쪽 뷰 또한 깨끗하게 해당 타입의 홈 대시보드 화면으로 초기화 및 복구됩니다.
