# EPUB 뷰어 전체 모드에서 휠 스크롤 및 중앙 클릭 오버레이 먹통 오류 수정

## 1. 개요 및 증상
- **현상**: EPUB 뷰어 감상 중 페이지 보기 모드에서도 마우스 휠을 굴려도 페이지가 넘어가지 않고, 화면 중앙 영역을 클릭해도 오버레이 컨트롤 바가 전혀 뜨지 않는 전체 먹통 오작동 현상이 발생했습니다.

## 2. 원인 분석
- **Iframe 이벤트 버블링 차단 및 핫스팟 간섭**:
  - EPUB 뷰어는 본문을 독립된 `Iframe` 구조로 렌더링합니다.
  - 브라우저 보안 아키텍처 상 `Iframe` 내부의 클릭이나 휠 이벤트는 부모 윈도우(`viewer.js`) 영역으로 버블링되지 않습니다.
  - 그런데 부모 윈도우의 투명 클릭 레이어인 **핫스팟(`common-viewer-hotspot`)**이 스크롤 모드가 아닐 때(`scrollMode === 'page'`) 화면 전체를 가로막고 있어, 사용자의 모든 휠 및 클릭 입력이 `Iframe` 내부로 유입되지 못하고 핫스팟에 가로막혀 완전 차단되었습니다.
  - 핫스팟이 차단함에 따라 `Iframe` 내부 `contents.document` 클릭 이벤트 훅도 가동되지 못해 중앙 클릭 오버레이 토글 또한 먹통이 되었습니다.

## 3. 해결 방안
- [viewer.js](file:///c:/project/media_server/static/js/viewer.js): `syncHotspotPointerEvents` 조율기의 분기식을 전면 개정했습니다.
  - EPUB 포맷(`isEpub`)인 경우, 페이지 보기와 스크롤 보기 모드를 불문하고 **핫스팟 레이어를 100% 무조건 비활성화(`display: none`)** 처리했습니다.
  - 이를 통해 데스크톱/모바일 전체 휠 스크롤링과 터치 스와이프 이벤트가 `Iframe` 영역의 epubJS 코어로 즉각 유입되도록 방해 요소를 완전히 소거했습니다.
  - 핫스팟 레이어가 소거됨에 따라 사용자의 클릭이 `Iframe` 내부 돔에 직접 닿게 되어, [viewer_epub.js](file:///c:/project/media_server/static/js/viewer_epub.js)에 선등록된 `Iframe contents` 클릭 훅이 정상 가동되어 중앙 영역 클릭 시 오버레이 제어 메뉴가 완벽하게 토글됩니다.

## 4. E2E 검증 결과
- EPUB 도서 진입 후 페이지 보기 및 스크롤 보기 모든 모드에서:
  - 마우스 휠을 굴렸을 때 페이지 전환 및 연속 스크롤이 끊김 없이 매끄럽게 가동됩니다.
  - 본문 임의 영역 클릭 시 오버레이 컨트롤 메뉴가 즉각 열리고 닫히는 정상적인 토글 조작성을 최종 확인했습니다.
