# EPUB 스크롤 보기 시 휠 스크롤 불가 및 터치 락 오류 수정

## 1. 개요 및 증상
- **현상**: EPUB 리더에서 보기 형식을 '스크롤 보기' 모드로 변경했을 때, 마우스 휠이나 트랙패드로 스크롤이 되지 않고 멈춰 있으며, 본문 우측 영역을 클릭할 때 스크롤 다운 대신 "마지막 페이지입니다" 라는 경고와 함께 다음 책으로 넘어가는 오작동이 유발되었습니다.

## 2. 원인 분석
- **핫스팟 레이어의 Iframe 이벤트 차단**: EPUB 뷰어는 문서 구조 특성상 독립된 `Iframe` 내부에 본문 콘텐츠가 렌더링됩니다.
- 그러나 화면 전체를 덮고 있는 투명 클릭 영역인 **핫스팟(`common-viewer-hotspot`)**이 스크롤 모드 상태에서도 여전히 포인터 이벤트를 상위에 덮어쓴 채 가로채고 있었습니다.
- 이로 인해 마우스 휠 이벤트와 드래그 드롭 이벤트가 `Iframe` 내부 영역으로 유입되지 못하고 유실되어 스크롤이 락이 걸렸으며, 임의의 클릭은 핫스팟 클릭(`nextPage() ➔ epubNextPage()`)으로 갈취당해 마지막 페이지 오동작을 낳았습니다.

## 3. 해결 방안
- [viewer.js](file:///c:/project/media_server/static/js/viewer.js): `syncHotspotPointerEvents` 함수 내부의 핫스팟 노출 분기식을 보강했습니다.
  - EPUB 스크롤 모드(`isScrollActive && isEpub`)인 경우, 화면 너비(innerWidth) 값과 무관하게 핫스팟 엘리먼트를 무조건 비활성화(`display: none`) 처리하도록 방어했습니다.
  - 이를 통해 휠 스크롤 이벤트가 `Iframe` 내부 돔으로 100% 무손실 전달되어 순정 휠 스크롤링이 가능해졌습니다.
  - (EPUB 뷰어는 이미 `Iframe` 내부 클릭 시 메뉴를 토글해 주는 독립된 훅이 등록되어 있어 핫스팟이 감춰져도 조작에 영향이 없습니다.)

## 4. E2E 검증 결과
- EPUB 스크롤 보기 진입 시 핫스팟 레이어가 즉각 차단되고, 본문 영역에서 마우스 휠을 굴릴 때 끊김 없이 부드럽게 전체 텍스트가 스크롤링되는 것을 최종 확인했습니다.
