# 🐛 도서 상세 요약 설명(Summary) 줄바꿈 보존 개선 (Bugfix Report)

## 1. 개요 및 증상
- **현상**: 도서 상세 화면에서 작품 설명(Summary) 내용에 있는 문단 구분과 줄바꿈 정보가 전부 사라진 채 하나의 긴 텍스트 줄로 붙어 표시되는 현상이 발생했습니다. 이로 인해 긴 분량의 시놉시스나 가독성이 중요한 줄거리 텍스트를 읽을 때 가독성이 매우 떨어지는 가독성 저하를 겪었습니다.

## 2. 원인 분석
- **백엔드 필터링 문제**: 스캐너의 HTML 태그 정화 유틸리티인 `clean_html_tags`에서 일괄적으로 정규식을 사용해 `<[^>]*>` 패턴을 공백 처리하며 html 태그를 소거했습니다. 이 과정에서 개행 역할을 하는 `<br>` 태그와 문단을 구획하는 `<p>`, `</p>` 태그가 모두 완전 삭제되어 개행 정보가 유실되었습니다.
- **프론트엔드 CSS 문제**: DB에 개행 문자(`\n`)가 보존되어 있다 하더라도, 상세 화면의 작품 설명 표시 영역인 `.book-summary-text` 클래스에 `white-space: pre-wrap;` 속성이 적용되지 않아 브라우저가 개행 문자를 렌더링하지 못하고 임의의 공백 문자 1개로 합쳐서 표현하는 한계가 존재했습니다.

## 3. 해결 방안 및 수정 사항
- **HTML 정화 유틸리티 개행 선치환 보완**:
  - `tools/scanner/metadata/__init__.py` 외 6개 파일에 분산 정의된 `clean_html_tags` 함수를 정비했습니다.
  - HTML 태그를 제거하기 전에, 줄바꿈 역할을 하는 `<br>` 태그는 `\n` 개행 문자로 치환하고, 문단 닫기 태그 `</p>`는 `\n` 개행 문자로 치환하며, 문단 열기 태그 `<p>`는 단순히 제거하여 개행 정보를 문자열 내에 보존하도록 개선했습니다.
- **상세 뷰어 스타일 시트 보완**:
  - `static/css/style.css` 내의 `.book-summary-text` 클래스에 `white-space: pre-wrap;` 속성을 주입하여 DB에서 전달된 개행 문자가 정상적으로 줄바꿈으로 렌더링되도록 디자인을 조정했습니다.
- **기존 데이터 일괄 정화**:
  - `tools/clean_db_summaries.py`에 적용된 필터 규칙을 개행 보존형으로 정비한 후 스크립트를 기동하여, `media_general.db` 내 기존 등록된 561건 도서의 줄거리 텍스트에 대해서도 줄바꿈이 정상 작동하도록 일괄 업데이트를 완수했습니다.

## 4. 검증 결과
- 수정 후 기존 DB의 텍스트가 줄바꿈 문자로 변환되었으며, CSS 스타일 시트 패치를 통해 상세 보기 화면에서 긴 작품 줄거리가 원문의 줄바꿈 그대로 읽기 편하게 멀티라인으로 배치됨을 정상 확인하였습니다.
