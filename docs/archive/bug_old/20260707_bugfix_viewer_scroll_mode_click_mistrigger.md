# 스크롤 모드일 때 뷰어 양측 영역 오클릭으로 인한 오버레이 토글 차단

## 1. 개요 및 증상
- **현상**: 만화, 텍스트, EPUB 등의 뷰어에서 '스크롤 모드'로 도서를 읽는 중, 다음/이전 흐름 조절 또는 터치 스크롤 제스처 시 화면 오른쪽이나 왼쪽 가장자리를 터치/클릭하면 불필요하게 **상하단 오버레이 메뉴(컨텍스트 메뉴)**가 팝업되어 독서를 방해하는 현상입니다.

## 2. 원인 분석
- `viewer.js`의 `initViewerClickToggle()`은 핫스팟이 꺼지는 스크롤 모드 상태일 때 뷰어 영역 내 어디를 클릭하든 무조건 `toggleComicOverlay()`를 실행시켰습니다.
- 이로 인해 스크롤 동작을 위해 가장자리를 누르거나 가벼운 탭 조작만 해도 오버레이 메뉴가 시도 때도 없이 오동작 팝업되었습니다.

## 3. 해결 방안
- **[viewer.js](file:///c:/project/media_server/static/js/viewer.js)**:
  - `initViewerClickToggle()` 내부 클릭 이벤트 핸들러에서 클릭 위치(`e.clientX`)와 브라우저 가로 해상도(`window.innerWidth`) 비례를 계산했습니다.
  - 클릭 지점이 화면의 가로 **30% ~ 70% 사이인 중앙 영역**일 때만 오버레이 바 토글이 동작하도록 제한 범위를 적용했습니다.
  - 양옆 30% 미만/70% 초과 가장자리 영역을 클릭할 때는 오버레이 팝업을 차단하여 스크롤 유휴 클릭을 허용했습니다.

## 4. E2E 검증 결과
- 스크롤 모드 진입 후 화면 중앙 영역을 클릭하면 오버레이 메뉴가 부드럽게 켜지고 꺼집니다.
- 화면 우측이나 좌측 가장자리 영역을 클릭할 시에는 더 이상 오버레이 메뉴가 오동작하여 노출되지 않음을 확인했습니다.
