# 버그 내역 및 해결 사항: 모바일 뷰어 스크롤 모드 컨텍스트(오버레이) 메뉴 중복 토글 버그

## 버그 내역 (Bug Description)
모바일 환경(특히 iOS Safari)에서 뷰어가 스크롤 모드(`viewer_scroll_mode='scroll'`)로 설정되어 있을 때, 화면 중앙을 터치하여 뷰어의 오버레이 메뉴(컨텍스트 메뉴)를 호출한 후 다시 닫으려고 화면을 터치하면, 메뉴가 닫혔다가 즉시 다시 열리는 현상("메뉴가 다시 떠")이 발생했습니다. 

## 영향도 (Impact)
- 모바일(iPhone 등) 기기 사용자가 만화, 텍스트, EPUB 등을 세로 스크롤 모드로 감상할 때 오버레이 메뉴를 정상적으로 닫을 수 없어 큰 불편과 사용성 저하를 초래했습니다.
- 터치 동작에 대해 `touchend` 이벤트와 지연된 `click` 이벤트가 연속적으로 발화하면서 오버레이를 두 번 연속 토글(`toggleComicOverlay()`)하게 된 것이 원인입니다.

## 수정 사항 (Modifications)
- **수정된 파일**: `static/js/viewer.js`
- **구현 방식**: 
  - `viewer_body` 영역에서의 `touchend` 이벤트 내에서 오버레이 메뉴 토글 로직이 수행될 때, 해당 시간을 `_lastTouchEndTime` 변수에 기록하도록 수정했습니다.
  - 뒤따라 들어오는 `click` 이벤트 핸들러에서 현재 시간과 `_lastTouchEndTime`을 비교하여, 500ms 이내에 `touchend`로 인한 토글이 선행된 경우 해당 `click` 이벤트를 무시(return)하도록 방어 코드를 추가했습니다.
  - iOS Safari 특성 상 터치 기기에서 발생한 합성(Synthetic) `click` 이벤트에 대해 `pointerType` 속성이 `undefined`이거나 `sourceCapabilities` 속성이 존재하지 않아 기존 방어 로직이 뚫리던 문제를 근본적으로 해결했습니다.

## 해결 사항 (Resolution)
사용자가 오버레이 메뉴를 닫기 위해 화면을 터치하면 한 번의 토글 동작(닫힘)만 정상적으로 실행되며, 이후 발생하는 중복 클릭 이벤트는 무시되어 메뉴가 다시 튀어나오는 현상이 완전히 해소되었습니다.
