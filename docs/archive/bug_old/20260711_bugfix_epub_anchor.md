# 버그 내역 및 개선사항 문서

## 1. 개요 및 버그 현상
* **발생 일시**: 2026-07-11
* **현상**: EPUB 뷰어에서 스크롤 모드와 페이지 모드 간 전환 시, 원래 보고 있던 위치가 아닌 엉뚱한 페이지(과거의 대화문 등)로 강제 이동하거나 화면이 먹통이 되는 현상 발생.
* **영향도**: 모드 전환 기능의 치명적인 오작동으로 인해 사용자 독서 경험이 심각하게 훼손됨.

## 2. 원인 분석
1. **DOM 찌꺼기(Remnants) 스캔 오류**: 기존 `TreeWalker` 방식을 사용해 앵커 텍스트를 추출할 때, `epub.js` 가 성능을 위해 남겨둔 보이지 않는(투명하거나 뷰포트 밖으로 밀려난) 과거 페이지의 HTML 요소들의 `getBoundingClientRect()` 좌표를 잘못 계산하여 "현재 화면 맨 위에 있는 글자"로 착각하고 저장함.
2. **짧은 검색어에 의한 중복 매칭**: 추출된 텍스트 중 15자만 잘라서 검색에 사용했기 때문에, 책 전체에 여러 번 등장하는 동일한 대화문이나 문구가 있을 경우 가장 먼저 검색된 앞쪽 챕터로 날아가는 치명적 매칭 오류 발생.

## 3. 수정 사항 및 해결 방법
1. **광선 추적(elementsFromPoint) 기반 추출로 전면 교체**: `TreeWalker` 를 버리고 브라우저의 `document.elementsFromPoint(x, y)` API를 도입하여, 특정 (x, y) 좌표에 실제 시각적으로 렌더링된 요소들만 수직 관통하여 찾아내도록 설계. 보이지 않는 DOM 찌꺼기 완벽 회피 성공.
2. **검색어 길이 확장**: 텍스트 중복을 막기 위해 앵커 텍스트 검색 길이를 15자에서 30자로 대폭 확장.
3. **현재 챕터(href) 이중 필터링 적용**: 만약 30자 문구가 중복되더라도, `rendition.currentLocation()`에서 추출한 현재 화면의 챕터(href)와 일치하는 결과를 최우선으로 선택하도록 이중 필터링 로직 추가.

## 4. 수정된 소스 파일
* `static/js/viewer/epub/runtime.js` (추출 로직 전면 재작성)
* `static/js/viewer/epub/page_mode.js` (복원 검색 로직 개선 및 필터링 추가)
* `static/js/viewer/epub/scroll_mode.js` (복원 검색 로직 글자수 확장 적용)
