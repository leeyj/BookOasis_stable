# EPUB 이미지 넘침 및 하단 슬라이더 비정상 이동 결함 조치

## 1. 개요 및 버그 내역
- **버그 1 (이미지 화면 넘침)**: EPUB 문서 내 삽화 이미지가 화면 크기나 뷰어 모드(특히 가로 다단 페이징 모드)보다 커서 옆 페이지를 침범하거나 화면 밖으로 삐져나가는 현상이 발생했습니다.
- **버그 2 (하단 슬라이더 비동기)**: 
  - 가로 페이징 모드에서 하단 슬라이더로 다른 청크/챕터를 선택했을 때, 텍스트가 바뀐 뒤 가로 스크롤 잔여 좌표가 리셋되지 않아 화면이 빈 영역이나 엉뚱한 위치를 가리켰습니다.
  - 세로 스크롤 모드에서 슬라이더 조작 시, 최대 스크롤 높이(`scrollHeight - clientHeight`)가 아닌 전체 영역(`scrollHeight`)을 단순 곱셈하여 스크롤 오차가 발생했고, 슬라이더를 끝까지 당겨도 마지막 챕터에 정확히 도달하지 못했습니다.

## 2. 변경 영향도
- **시각적 완성도**: EPUB 삽화 이미지가 페이지/스크롤 모드에 맞는 상한 높이(`70vh` 및 `85vh`)에 제한되고 중앙에 가지런히 안착하여 다단 레이아웃이 침범당하거나 깨지지 않습니다.
- **슬라이더 제어 신뢰성**: 슬라이더를 드래그하는 즉시 가로 페이징 뷰어가 맨 왼쪽(`scrollLeft = 0`)으로 자동 복원되며, 세로 연속 스크롤 역시 스크롤 상한 임계치를 적용한 정밀 백분율로 마지막 페이지까지 정확하게 추적 오차 없이 스크롤됩니다.

## 3. 수정 사항 및 파일 정보
- **[services/stream_service.py](file:///c:/project/media_server/services/stream_service.py)**:
  - 이미지 정제 마크업 생성 시 기본 인라인 스타일에 `max-height: 75vh; object-fit: contain;` 제한을 기본 반영하여 1차 오버플로우를 제어했습니다.
- **[static/js/viewer_txt.js](file:///c:/project/media_server/static/js/viewer_txt.js)**:
  - `applyDynamicParagraphStyles` 내에 이미지 스타일 강제 제어 코드를 추가해 뷰어 스크롤 모드에 따라 70vh/85vh 높이를 동적으로 강제 보정합니다.
  - `txtSliderChange` 함수를 대대적으로 정비하여 가로 페이징 모드일 때 스크롤 위치 초기화(`scrollLeft = 0`)를 추가하고, 세로 스크롤 모드일 때 scrollHeight가 아닌 `maxScroll`과 `targetIdx / (length - 1)` 비율을 연산하도록 수식을 수정했습니다.

## 4. 해결 사항 및 E2E 최종 확인
- 가로 모드 상태에서 슬라이더를 이리저리 이동해 보았을 때 본문 시작점으로 깔끔히 맞춰지고, 큰 해상도의 이미지 삽화 역시 페이지 비율을 유지하며 화면 안에 안착하는 것을 검증했습니다.
- 세로 모드 상태에서 슬라이더를 맨 우측 끝으로 이동 시 오차 없이 최종 장 텍스트에 안착하는 것이 확인되었습니다.
