# TXT/EPUB 통합 뷰어 내 앵커 텍스트 기반 정밀 읽기 위치 복원 구현

## 1. 개요 및 결함 내역
- **현상**: 기존 `epub.js` 시절에는 스크롤<->페이지 보기 모드 전환 시 화면 맨 위에 노출되고 있던 글자(텍스트 노드)를 기억해 두었다가, 전환 완료 후 그 텍스트를 책 내용 중에서 검색하여 원래 읽던 위치로 정확하게 스크롤을 맞춰 주었습니다. 그러나 이번에 `epub.js`를 제거하고 통합 텍스트 뷰어([viewer_txt.js](file:///c:/project/media_server/static/js/viewer_txt.js))로 경량화하는 과정에서 해당 앵커 기능이 누락되어, 모드 전환 시 세밀한 위치를 기억하지 못하고 챕터 첫 줄 등으로 위치가 크게 튕겨 나갔습니다.

## 2. 변경 영향도
- **완벽한 복원 품질**: 모바일/PC 등 디바이스 해상도나 다단 배치 개수, 줄 간격이 바뀌더라도 현재 읽고 있던 텍스트 구절을 직접 찾아내어 그 줄(Line) 좌표로 완벽하게 복원되므로 오차가 전혀 발생하지 않습니다.

## 3. 수정 사항 및 파일 정보
- **[static/js/viewer_txt.js](file:///c:/project/media_server/static/js/viewer_txt.js)**:
  - `getTxtAnchorInfo()` 함수 신설: 뷰어 화면의 스크롤 오프셋을 피한 좌상단 본문 안쪽 지점(`elementFromPoint(x, y)`)을 타격하여, 최상단에 실제 노출되어 렌더링된 텍스트 중 공백을 제거한 30글자를 앵커 키값으로 백업합니다.
  - `restoreTxtAnchorInfo()` 함수 신설: 백업된 30자 키값을 현재 콘텐츠 노드 트리 내부에서 역추적하여 매칭되는 텍스트 엘리먼트를 찾습니다.
    - 세로 스크롤 모드 복원 시: 찾은 요소의 누적 `offsetTop` 위치로 스크롤바 이동.
    - 가로 페이지 모드 복원 시: 찾은 요소의 누적 `offsetLeft` 위치를 기준으로 현재 컬럼 너비 단위에 맞춰 스크롤바(`scrollLeft`) 정밀 동기화.
  - `applyTxtSettings` 내부에 해당 앵커 백업 및 복원 호출 구조를 융합하고, 복원 실패 시에만 기존 비율 오프셋 공식을 Fallback으로 타도록 이중화 안전장치를 적용했습니다.

## 4. 해결 사항 및 최종 확인
- EPUB 도서 독서 도중 페이지 중간의 특정 문장을 보는 상태에서 가로 다단 페이지 모드 <-> 세로 스크롤 모드를 상호 전환 시, 한 글자도 어긋나지 않고 해당 문장 화면 위치로 스크롤바가 칼같이 일치 복원되는 것을 검증 완료했습니다.
