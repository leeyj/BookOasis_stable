# TXT/EPUB 뷰어 모드 전환 시 읽기 위치 초기화 결함 조치

## 1. 개요 및 버그 내역
- **현상**: 가로 페이징 모드와 세로 연속 스크롤 모드를 전환할 때, 읽던 도서 위치가 유지되지 않고 무조건 첫 페이지(또는 첫 챕터)인 `0`으로 초기화되는 버그가 발생했습니다.
- **원인**: 세로 스크롤 모드에서 가로 페이지 모드로 전환할 때 스타일 시트 클래스가 변경되면서 스크롤 컨테이너의 내부 크기가 바뀌게 됩니다. 이로 인해 브라우저 레이아웃 엔진이 임시로 scrollTop을 `0`으로 당겨버리고, 이때 리스너로 등록된 `scrollHandler`가 비동기적으로 호출되어 현재 `scrollTop = 0`인 것을 보고 읽기 진행 인덱스 `currentChunkIdx`를 `0`으로 덮어써버려 발생하는 레이아웃 타이밍 버그였습니다.

## 2. 변경 영향도
- **진척도 유지성 보장**: 이제 사용자가 페이지 모드와 스크롤 모드를 빈번하게 교차 전환하더라도, 스타일 변경에 의한 브라우저 임시 스크롤 리셋 이벤트에 영향을 받지 않고 현재 읽고 있던 위치를 정확하게 고수하여 전환이 매끄럽게 처리됩니다.

## 3. 수정 사항 및 파일 정보
- **[static/js/viewer_txt.js](file:///c:/project/media_server/static/js/viewer_txt.js)**:
  - `applyTxtSettings` 함수 진입 직후 스크롤 컨테이너의 이벤트 리스너(`__txtScrollHandler`)를 일시 분리(`removeEventListener`)합니다.
  - 레이아웃 스타일 적용, DOM 렌더링, 폰트 및 설정 복원이 모두 완료되고 스크롤바 위치 지정을 마친 뒤, `setTimeout` 콜백 또는 안전한 블록 끝에서 리스너를 다시 복원 바인딩하여 렌더링 도중의 레이아웃 리셋 이벤트를 원천적으로 차단했습니다.

## 4. 해결 사항 및 E2E 최종 확인
- 세로 스크롤 모드에서 책 중간 지점까지 읽은 후 설정 모달을 열어 가로 다단 페이지 모드로 변경해 본 결과, 중간에 읽던 챕터 및 가로 시작 좌표로 정확하게 유지 복원되는 것을 검증하였습니다.
- 반대로 가로 다단 페이지 모드에서 세로 스크롤 모드로 전환할 때도 읽던 챕터 위치 비율에 맞춰 정확한 세로 스크롤바로 전환 이동하는 것을 확인했습니다.
