# 만화 뷰어 스크롤 모드 프리로드 기능 차단 버그 개선

## 1. 버그 내역 및 증상
- 만화 뷰어를 '스크롤 모드'로 감상할 때, 다음 에피소드나 다음 페이지들의 사전로드(Preload) 범위를 20장으로 높게 설정했음에도 불구하고 스크롤을 내릴 때 하단부에 검은 영역(이미지 로딩 지연 공백)이 계속해서 발생하는 현상.

## 2. 원인 분석
- **네이티브 레이지 로딩의 간섭**: 만화 스크롤용 `<img>` 생성 시 `loading="lazy"` 속성을 사용함. 자바스크립트가 사전로드를 지시하여 `src`에 이미지 스트리밍 URL을 주입해도, 크롬 등 브라우저 단에서 "해당 이미지가 뷰포트에 도달하기 전까지 다운로드를 원천 차단"하여 사전로드가 완전히 오작동함.
- **좁은 교차점 감지 마진**: `IntersectionObserver` 인스턴스 옵션의 `rootMargin`이 `'0px'`로 극도로 타이트하게 고정되어 있어, 이미지가 화면 영역에 완전히 닿은 후에야 네트워크 요청이 뒤늦게 시작되어 스크롤 속도보다 이미지 다운로드 속도가 늦어짐.

## 3. 조치 사항
1. **`img.loading = 'lazy'` 속성 제거 (`static/js/viewer/renderer.js`)**:
   - 브라우저의 네이티브 레이지 로딩 간섭을 제거하여 자바스크립트 제어 큐에서 할당한 사전로드 20장 이미지가 백그라운드 네트워크 커넥션을 통해 즉시 병렬 다운로드되도록 개선함.
2. **감지 경계 여백 확장 및 감도 미세 조정**:
   - `IntersectionObserver` 의 `rootMargin`을 `'0px'`에서 **`'2000px'`**로 확장함. 이미지가 뷰포트 하단 2000px 범위 내에 들어오는 시점부터 조기에 감지하여 미리 로드를 시작함.
   - 교차율 기준 임계값(`threshold`)을 `0.3`에서 `0.1`로 하향하여 조금 더 빠른 반응성으로 로딩되도록 제어함.

## 4. 해결 확인 및 영향도
- 스크롤을 아주 빠르게 내리더라도, 2000px 범위 전방의 이미지들이 백그라운드에서 이미 완전하게 다운로드 완료되어 있어 검은 영역 노출 없이 부드러운 스크롤링 감상이 가능함.
