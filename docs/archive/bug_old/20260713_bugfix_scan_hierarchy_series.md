# 🐛 계층 기반 표준 시리즈 그룹화 조치

## 1. 버그 내역 및 증상
- 이미지 폴더 가상 책(`imgdir`) 스캔 시, 사용자의 시리즈 폴더 구조(예: `데스노트 컬러판/데스노트 컬러판 01권/`)가 존재함에도 불구하고 각 개별 권수 폴더명이 그대로 `series_name`으로 DB에 기록되어, 1권마다 각각 독립된 카드(시리즈)로 쪼개져 나열되는 현상이 발생했습니다.

## 2. 원인 분석
- 정규식으로 강제 소거를 진행할 경우 사용자마다 포맷이 천차만별이어서 역효과(원본 제목 내 숫자 소실 등)가 발생할 수 있습니다.
- 따라서 "시리즈 폴더 하위에 개별 권수 폴더들을 구성한다"는 표준 규격 모델 하에서, 라이브러리 루트 기준 계층 정보를 추출하는 것이 적합합니다.
- 기존 스캐너는 카테고리 루트 경로의 마지막 폴더명과 겹치는 경우 등에 대한 정밀한 계층 추적이 누락되어 하위 폴더명을 우선적으로 채택하는 결함이 있었습니다.

## 3. 조치 사항
- **[engine.py](file:///c:/project/media_server/tools/scanner/engine.py)**:
  - `process_folder_task` 호출 시, 라이브러리의 물리 루트 경로(`physical_path`)를 추가 인자(`library_root`)로 전달하도록 파이프라인을 확장했습니다.
- **[tasks.py](file:///c:/project/media_server/tools/scanner/tasks.py)**:
  - 라이브러리 루트 경로를 기준으로 `root` 경로의 상대 디렉토리를 구하고, 초성 폴더(예: `ㄷ`)를 제외한 첫 번째 폴더명을 공통 시리즈명(`series_name`)으로 최우선 추출하는 알고리즘을 도입했습니다.
  - 상위 계층 구조가 마땅치 않을 때에만 Fallback 처리를 하며 표준 규격을 위해 현재 폴더명을 유지하도록 조치했습니다.
  - 가상 책의 `imgdir_series_name` 에도 이와 같이 계층 정규화가 끝난 시리즈명을 대입하도록 단일화했습니다.

## 4. 해결 확인 및 영향도
- 상위 시리즈 폴더 계층이 완벽히 인지되어, 개별 권수 이미지 책들이 하나의 단일 카드 밑에 순차적으로 묶이게 되었습니다.
