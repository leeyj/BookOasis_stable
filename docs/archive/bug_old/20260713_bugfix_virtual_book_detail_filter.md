# 이미지 폴더 가상 책 상세 목록 필터 오류 수정

## 1. 버그 내역 및 증상
- 이미지 폴더를 기반으로 가상 책(imgdir)을 스캔하면, 전체 책의 권수(예: 4권)가 정상적으로 집계/표시됨에도 불구하고 도서 상세 페이지 진입 시 '단행본 목록'에는 1권만 노출되는 현상 발생.

## 2. 원인 분석
- `services/book_detail_service.py`의 `get_media_detail` 함수 내에서 `restrict_same_directory` 필터가 설정되어 있는 경우, 첫 번째 도서의 물리 디렉토리를 기준으로 동일한 디렉토리에 있는 도서들만 반환함.
- 일반 ZIP/CBZ 압축 파일은 한 디렉토리에 모여 있어 문제가 없으나, 가상 책(`__folder__.imgdir`)의 경우 각 권마다 하위 디렉토리를 생성함:
  - 1권: `.../평범한 연애는 할 수 없어 01권 (리디)#198/__folder__.imgdir`
  - 2권: `.../평범한 연애는 할 수 없어 02권 (리디)#198/__folder__.imgdir`
- 이로 인해 각 가상 책의 `os.path.dirname(file_path)`가 다르게 되어 1권을 제외한 나머지 권수들이 필터링 과정에서 탈락하는 것이 원인이었음.

## 3. 조치 사항
- **상세 서비스 디렉토리 필터링 로직 보완 (`services/book_detail_service.py`)**:
  - `get_comparison_dir` 헬퍼 함수를 추가하여 가상 책 경로인 `__folder__.imgdir`로 끝나는 경우에는 상위 디렉토리의 부모 디렉토리(시리즈 디렉토리)까지 2단계 거슬러 올라가서 비교하도록 교정함.
  - 가상 책 이외의 일반 도서 파일은 기존과 동일하게 부모 디렉토리 단계를 기준으로 비교를 수행하여 호환성을 유지함.

## 4. 해결 확인 및 영향도
- 수정 후 '평범한 연애는 할 수 없어' 등 가상 책 구조의 상세 리스트 페이지를 확인한 결과, 기존 1권만 노출되던 화면에서 1~4권 전체가 '단행본 목록'에 정상 노출 및 정렬되는 것을 검증함.
