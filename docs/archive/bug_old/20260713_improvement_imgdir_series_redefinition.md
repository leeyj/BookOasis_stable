# 이미지 폴더 가상 책 시리즈명 등록 기준 재정립

## 1. 개요 및 요구사항
- 이미지 파일들(JPG, PNG 등)이 존재하는 최하위 폴더를 가상 책(imgdir)의 **"권(Volume)"**으로 정의하고, 해당 "권" 폴더의 바로 상위 폴더(부모 폴더)를 무조건 **"시리즈(Series)"**로 지정합니다.
- 카테고리(라이브러리 물리 경로) 하위에 설정된 중간 경로들(예: 초성 폴더 `ㄷ`, 카테고리 중간 정렬 경로 `야만화/A` 등)은 무조건 무시하고 오직 시리즈 부모 폴더명만 추출하여 시리즈명으로 적용합니다.

## 2. 기존 로직의 한계
- 기존에는 카테고리 루트 기준 상대 경로를 상단에서부터(Top-down) 탐색하며 초성 폴더가 아닌 첫 번째 경로를 시리즈명으로 설정하였습니다.
- 이로 인해 아래와 같은 경우 중간에 존재하는 디렉토리(`야만화`)가 잘못 시리즈명으로 등록되는 오작동이 있었습니다.
  - `comics/개인모음/야만화/A/아앙~/아앙~ 1권/01.jpg`
    - 기존 매핑 결과: 시리즈명 `야만화`
    - 기대 매핑 결과: 시리즈명 `아앙~`

## 3. 조치 사항
- **스캐너 태스크 파싱 로직 개선 (`tools/scanner/tasks.py`)**:
  - `has_imgdir_candidate` 조건 분기 시, 기존 상향식 `series_name` 변수를 직접 할당하는 대신 `os.path.basename(os.path.dirname(root))`을 통해 이미지 존재 디렉토리의 부모 폴더명을 동적으로 조회하도록 변경.
  - 추출된 시리즈 부모 폴더명에 대해 정규식 필터(`re.sub(r'^\[(?:단행|연재|소설|만화|웹툰|일반)\]\s*', '', ...).strip()`)를 적용하여 대괄호 접두어 제거를 정상 실행 후 시리즈명으로 할당.
  - 부모 폴더 조회가 불가능할 경우에만 기존 `series_name`을 폴백으로 사용하도록 예외 처리.

## 4. 검증 결과
- `comics/개인모음/ㄷ/데스노트 컬러판/데스노트 1권/01.jpg`의 경우:
  - 도서명(title): `데스노트 1권`
  - 시리즈명(series_name): `데스노트 컬러판` (중간 경로 `ㄷ` 완전 무시 확인)
- `comics/개인모음/야만화/A/아앙~/아앙~ 1권/01.jpg`의 경우:
  - 도서명(title): `아앙~ 1권`
  - 시리즈명(series_name): `아앙~` (중간 경로 `야만화/A` 완전 무시 확인)
- 스캔 및 데이터베이스 저장 테스트 시 지정된 부모 폴더명이 무결하게 바인딩되는 것을 검증 완료.
