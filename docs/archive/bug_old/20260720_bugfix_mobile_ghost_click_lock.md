# 20260720 — 모바일 햄버거 토글 고스트 클릭(Ghost Click) 방지 조치 완료

## 버그 내역

### 현상
- 모바일 뷰어에서 카테고리를 터치하여 이동하고 메뉴가 닫힌 뒤, 다시 햄버거 메뉴를 눌렀을 때 제대로 펼쳐지지 않고 아이콘만 `X` 로 유지되거나 레이아웃 오동작이 유발되는 현상.

### 근본 원인
- **터치 고스트 클릭 (Ghost Click)**: 모바일 브라우저는 화면 터치(`touchstart`/`touchend`) 발생 시 즉시 카테고리 선택 및 사이드바 닫기(bars 아이콘 복원)를 처리하지만, 약 300ms 뒤에 동일 좌표에 가상의 마우스 `click` 이벤트를 한 번 더 트리거함.
- 닫혀서 제자리에 노출된 햄버거 버튼에 이 고스트 클릭이 그대로 유입되면서 `toggleSidebarMenu()`가 오발사되어 메뉴가 즉각 다시 열려(X 아이콘 상태로 오버라이드) 버리고, 이 급격한 리액트 렌더링 프레임 충돌로 인해 높이가 0이 된 상태로 햄버거 메뉴가 멈췄던 것.

## 영향도
- 모바일 기기 사용자가 카테고리를 전환한 뒤 다른 카테고리로 2차 이동하기 위해 메뉴를 열려고 하면 메뉴가 먹통이 되는 치명적인 모바일 사용성 결함 유발.

## 수정 사항

### 수정 파일 목록

#### `static/js/sidebar_manager.js`
- 350ms 디바운스 목적의 터치 타임 락(`lastToggleTime` 타임스탬프 가드) 장착.
- `toggleSidebarMenu` 함수에 진입 가드를 씌워 350ms 이내에 중복 접수되는 딜레이 고스트 클릭을 전면 무시.
- `initSidebarAutoClose()` 에 의한 자동 닫힘 발생 시점에도 `lastToggleTime`을 갱신하여, 닫힌 직후 발생하는 300ms 딜레이 고스트 클릭이 햄버거 버튼을 오작동시키는 현상을 원천 차단.

## 해결 사항
- 모바일 가상 터치 검증을 통해 카테고리 이동 후 곧바로 햄버거 메뉴를 터치하더라도 오동작이나 꼬임 없이 100% 안정적으로 토글 제어가 수행됨을 확인하였습니다.
