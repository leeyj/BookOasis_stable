# 일반 환경설정 탭 4대 성격별 섹션(UI/스캐너/시스템/보안) 구조화 리팩토링

## 1. 구현 개요
- 기존에는 [일반 설정] 탭에 뷰어, 스캐너, 메모리, 크론, 네트워크, SSO 등의 20여 개 설정 항목이 단일 리스트로 일관성 없이 나열되어 시각적으로 지저분했습니다.
- 이를 사용자의 의도와 성격에 따라 **4개의 명확한 카드 섹션 박스(UI & 뷰어 환경, 백그라운드 스캐너, 시스템 및 리소스, 네트워크 및 보안)**로 분할 및 그룹화하여 깔끔하고 세련되게 정돈했습니다.

## 2. 주요 섹션 구조
1. **🎨 1. 화면 및 뷰어 환경 설정 (`#a855f7`)**
   - 도서 카드 너비, 1회당 로딩 제한 수, 뷰어 글자크기/글꼴, 만화 로딩 지연시간, 검색 단축키, 최근 읽은 도서 개수, 사이드바 전체보기/상단배치/다읽은 도서삭제/태그필터/안내배너 스위치 모음.
2. **⚡ 2. 백그라운드 스캐너 설정 (`#38bdf8`)**
   - Lazy 표지 스캐너 크론 주기 및 [지금 실행] 버튼, 개별 파일 용량 제한, 1회 세션 누적 용량 한도, 스캐너 실행 로그 작성 옵션, HDD 적극 웜업 스위치.
3. **⚙️ 3. 시스템 및 메모리 리소스 설정 (`#34d399`)**
   - 스캐너 여유 메모리 하한, 스캐너 프로세스 메모리 제한, DB 커넥션 풀 크기, 시스템 타임존.
4. **🔐 4. 네트워크 및 보안 설정 (`#f87171`)**
   - rclone 원격 제어(RC) API 주소, Proxy Header Auth (SSO 리버스 프록시 로그인) 연동 및 경고 카드.

## 3. 검증 결과
- 모든 설정 input/select/checkbox의 ID 및 name 속성이 그대로 유지되어 기존 `submitGeneralSettings` / `loadGeneralSettings` 기능과 100% 정상 호환됨.
- 개별 서브 카드 렌더링으로 각 설정의 위치를 직관적으로 파악할 수 있고 화면 가독성이 대폭 향상됨.
