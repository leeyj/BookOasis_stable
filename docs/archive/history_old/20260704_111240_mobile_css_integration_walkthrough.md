# 모바일 및 데스크톱 반응형 CSS 추가 (데스크톱 사이드바 접기 추가) 워크쓰루

데스크톱용 기존 CSS 코드를 전혀 건드리지 않고 모바일 및 태블릿 환경(최대 가로 너비 1200px 이하)에서 최적화된 레이아웃을 제공함과 동시에, 데스크톱 화면 환경에서도 좌측 사이드바를 자유롭게 접고 펼칠 수 있는 인터랙티브 토글 기능을 추가했습니다.

## 변경 내용

### 1. 웹 템플릿 연동 및 햄버거 버튼 추가
- [tab_media_library.html](file:///c:/project/media_server/templates/components/tab_media_library.html) 파일의 기존 스타일시트 로드 구문 밑에 `mobile.css`를 로드하는 코드를 추가했습니다.
  - 미디어 쿼리 속성: `media="screen and (max-width: 1200px)"` (태블릿 가로/프로 라인 대응을 위해 **1200px**로 한계 확장)
- 사이드바 헤더 영역에 모바일 전용 햄버거 메뉴 토글 버튼(`btn-sidebar-toggle`)을 추가했습니다.
- 메인 콘텐츠 상단 영역(`.library-header`)에 데스크톱 전용 사이드바 토글 버튼(`btn-sidebar-toggle-desktop`)을 신규 배치했습니다.
- 사이드바 카테고리 목록과 설정/프로필 메뉴 영역을 접고 펼칠 수 있는 래퍼 컨테이너(`.sidebar-collapsible-content`)로 감싸 정돈했습니다.
- 사이드바 메뉴를 토글하는 인라인 자바스크립트 함수 및 메뉴 아이템 클릭 시 모바일 크기일 때 사이드바를 자동으로 접어주는 리스너 스크립트를 파일 하단에 삽입했습니다.

### 2. 데스크톱 사이드바 접기 제어 (JS & CSS)
- **접기 동작 구현**: 자바스크립트 `toggleDesktopSidebar()` 함수를 구현하여 데스크톱 버튼 클릭 시 `.library-sidebar`에 `.collapsed` 클래스를 토글하도록 구현했습니다.
- **상태 기억 기능**: `localStorage`를 연동하여 사용자가 사이드바를 접어둔 상태를 영구 기억(`desktopSidebarCollapsed`)하고, 페이지 새로고침 시에도 동일한 상태가 유지되도록 로직을 추가했습니다.
- [style.css](file:///c:/project/media_server/static/css/style.css)에 사이드바 접힘 상태 스타일(`.library-sidebar.collapsed`)을 정의하여 너비(`width: 0`, `min-width: 0`)와 투명도를 소거하고, `transition` 애니메이션 효과를 부여해 부드럽게 슬라이드 닫기/열기가 되도록 연출했습니다.

### 3. 스타일시트 정의 ([mobile.css](file:///c:/project/media_server/static/css/mobile.css))
- `.media-library-container` 내 플렉스 방향을 가로(`row`)에서 세로(`column`) 구조로 변경.
- `.library-sidebar`를 고정 너비에서 `100%` 너비로 전환하고, 상단 영역으로 배치되도록 변경.
- **햄버거 메뉴 구현**: 모바일/태블릿 너비(<= 1200px)에서 카테고리 메뉴 목록이 기본적으로 접혀 숨겨지며, 햄버거 버튼 클릭 시에만 세로 방향 리스트로 슬라이드되어 깔끔하게 펼쳐지도록 스타일링했습니다.
- 사이드바 메뉴의 지저분한 바둑판 배열을 데스크톱처럼 **깔끔한 세로 정렬(Vertical layout)**로 복구하여 미적 어색함을 제거했습니다.
- **환경설정 탭 가로 스크롤 추가**: 모바일/태블릿의 좁은 화면에서 환경설정 탭 버튼들이 강제로 찌그러져 세로로 한 글자씩 출력되는 문제를 해결하기 위해, 탭 영역에 가로 스크롤(`overflow-x: auto; flex-wrap: nowrap;`)을 적용하고 개별 버튼이 형태를 온전히 보존(`flex-shrink: 0; white-space: nowrap;`)하도록 개선했습니다.
- **설정 테이블 반응형 처리**: 테이블 데이터가 구겨져 세로로 떨어지는 현상을 막기 위해 `.settings-table-wrapper`에 가로 스크롤을 부여하고 테이블의 최소 너비를 유지시켰습니다.
- **도서 상세 뷰 및 단행본 리스트 레이아웃 세로 정렬**: 
  - 도서 상세 헤더 패널(`.detail-header-panel`) 및 하단 2열 구조(`.detail-layout`)를 가로(좌|우) 배치에서 **세로(위|아래) 배치**로 전환하여 모바일 화면에서 잘림 현상 없이 깔끔하게 렌더링되도록 스타일링했습니다. 썸네일 커버 및 메타 태그들도 모바일 환경에 맞춰 가독성 높게 중앙 정렬되도록 조정했습니다.
  - 단행본(볼륨) 개별 카드 리스트 항목(`.volume-card`)의 가로(좌 썸네일 | 우 메타정보) 레이아웃을 **세로(위 썸네일 | 아래 메타정보 및 버튼) 배치**로 전환했습니다.
  - 긴 경로 텍스트로 인해 레이아웃이 뭉개지던 디렉토리 경로(`.volume-path`)를 모바일 뷰포트에서 **숨김 처리(`display: none;`)** 하였습니다.
  - **이어보기 버튼 정렬 튜닝**: "이어보기/시작하기" 버튼(`.btn-read`)이 모바일에서 가로 100% 영역을 차지함과 동시에, 버튼 내 재생 아이콘과 텍스트가 좌측에 치우치지 않고 **정가운데 정렬(`display: inline-flex; justify-content: center; align-items: center;`)**되도록 튜닝했습니다.
  - **데스크톱 전용 버튼 숨김**: 모바일 뷰(<= 1200px) 상태일 때는 데스크톱용 토글 햄버거 버튼이 보이지 않도록 `display: none !important;` 처리하고 모바일 전용 햄버거 버튼만 작동되도록 격리했습니다.

## 검증 결과

### 1. 데스크톱 뷰 (너비 > 1200px)
- 모바일용 햄버거 버튼이 보이지 않으며, 상단 제목 옆의 데스크톱용 햄버거 버튼을 누르면 좌측 사이드바가 우측으로 부드럽게 접히거나 열립니다.
- 사이드바를 접었을 때 메인 콘텐츠 영역이 화면 전체로 꽉 차서 시원하게 도서 목록을 볼 수 있습니다.
- 접힌 상태에서 페이지 새로고침을 해도 접힌 상태가 그대로 유지됩니다.

### 2. 모바일 및 태블릿 뷰 (너비 <= 1200px)
- 아이패드 미니 가로 모드를 포함한 태블릿 기기 전체 영역에서 데스크톱용 햄버거 버튼은 완전히 숨겨지고, 모바일 전용 상단 햄버거 메뉴를 통해 터치 토글식 카테고리 이용이 가능합니다.
- 단행본 목록, 뷰어 오버레이 조작반, 환경설정 탭 등이 찌그러짐이나 글자 깨짐 없이 일목요연하게 동작합니다.
