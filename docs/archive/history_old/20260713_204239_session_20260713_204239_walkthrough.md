# 비활성화된 메타데이터 플러그인 노출 방지 결함 수정 완료 보고서

환경설정에서 비활성화한 메타데이터 검색 플러그인(알라딘 오늘의 신간 데스크 등)이 개별 도서 수동 검색창의 검색 소스 드롭다운 목록에 노출되던 결함을 해결하였습니다.

## 변경된 사항 (Changes Made)

### 1. 플러그인 활성(enabled) 여부 필터링 연동
- **수정 파일**: [metadata_service.py](file:///c:/project/media_server/services/metadata_service.py)
- **조치 내용**: 
  - `/api/media/metadata/plugins` 호출 시 실행되는 `get_searchable_plugins()` 정적 메소드 내부에서 모든 메타데이터 제공자 목록(`MetadataFactory.get_all_searchable_providers()`)을 조회한 후, `enabled` 값이 `True`로 설정된 활성 플러그인만 필터링하여 응답을 구성하도록 리스트 컴프리헨션을 적용하였습니다.
  - 이 조치를 통해 환경설정에서 사용자가 '비활성화'로 전환한 검색 소스는 수동 검색 모달창의 드롭다운 선택지에 공급되지 않게 되었습니다.

## 검증 결과 (Verification Results)
- **수동 검색 선택박스 검증**:
  - '환경설정 > 플러그인'에서 특정 플러그인을 꺼둔 상태로 도서 우클릭 메타데이터 검색 모달창을 열었을 때, 비활성화된 플러그인이 더 이상 리스트에 포함되지 않는 것을 최종 확인하였습니다.
