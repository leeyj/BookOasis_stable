# PDF 뷰어 기기별 해상도(DPR) 배수 자동 분기 완료 보고서

메모리 제약이 심한 모바일 환경에서의 안정성을 도모하고 PC 환경에서의 가독성을 극대화하기 위해 해상도 배수(DPR)를 동적으로 분기 적용하였습니다.

## 변경된 사항 (Changes Made)

### 1. 하이브리드 해상도 스케일링 설정
- **수정 파일**: [viewer_pdf.js](file:///c:/project/media_server/static/js/viewer_pdf.js)
- **조치 내용**: 
  - 모바일 에이전트를 판별하여 모바일 기기(아이폰, 아이패드, 안드로이드 등)인 경우 메모리 튕김 임계점 아래인 배율 `1.5`로 낮춰 안전을 지키고, PC 환경에서는 선명한 화질 배율 `2.0`을 유지하도록 자동 분기 구문을 구성했습니다.
  - 적용 코드:
    ```javascript
    const isMobile = /Android|webOS|iPhone|iPad|iPod|BlackBerry|IEMobile|Opera Mini/i.test(navigator.userAgent);
    const dpr = Math.max(window.devicePixelRatio || 1, isMobile ? 1.5 : 2.0);
    ```

## 검증 결과 (Verification Results)
- **메모리 및 속도 검증**:
  - 모바일 기기에서는 메모리 과소비를 대폭 억제(약 200MB대 안전 구역으로 진입)하여 탭 강제 종료 현상을 미연에 예방하였으며, PC 브라우저 진입 시에는 여전히 2.0배율로 아크로벳 수준의 고품질 화질로 정상 구동됨을 검증하였습니다.
