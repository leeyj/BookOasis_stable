# 대시보드 모바일(iOS Safari / 안드로이드) 렌더링 성능 최적화 계획

## 1. 개요 및 근본 원인
iOS Safari(WebKit) 환경에서 대시보드 로딩 및 스크롤 시 발생하는 극심한 버벅임(Stuttering)을 해결하고, 안드로이드 및 iOS 모두에서 부드럽고 쾌적한 렌더링 성능을 보장하기 위한 최적화 작업입니다.

### 주요 원인
1. **`will-change` 오남용**: 모든 `.book-card` 및 커버 이미지에 상시 부여된 `will-change`로 인해 WebKit 하드웨어 가속 레이어가 수십 개 독립 생성되어 GPU 메모리 고갈 및 레이어 스래싱 발생.
2. **이미지 동기 디코딩**: `<img>` 태그에 `decoding="async"` 미지정으로 대시보드 로드 시 메인 UI 스레드 블로킹.
3. **불필요한 과도한 CSS 계산**: 호버/터치 애니메이션 및 반투명 블러(`backdrop-filter`) 효과의 비효율적 스코프.

---

## 2. 작업 목표 및 단계별 수행 계획

- [ ] **1단계: CSS GPU 레이어 최적화 (`static/css/style.css`, `static/css/mobile.css`)**
  - `.book-card` 및 `.book-card-cover img`의 상시 `will-change` 제거 및 호버 시로 변경.
  - 하드웨어 가속 최적화 프로퍼티(`backface-visibility`, `transform: translateZ(0)`) 정밀 조정.
- [ ] **2단계: JS DOM & 이미지 디코딩 최적화 (`static/js/ui.js`)**
  - `createBookCard` 함수 내 `<img>` 태그 생성 시 `decoding="async"` 및 `loading="lazy"` 속성 강화.
- [ ] **3단계: 검증 및 문서화**
  - 대시보드 렌더링 및 모바일 호환성 검증.
  - `./docs/bug/20260723_bugfix_dashboard_ios_webkit_performance.md` 문서 작성.
  - `./tools/collect_docs.py` 실행하여 문서 관리 시스템 반영.
