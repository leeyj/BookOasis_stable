# 도서 상세 뷰 갱신/뷰어 닫기 시 목록 스크롤 위치 유실 버그 수정 계획

## 1. 개요 및 근본 원인
도서 상세 페이지 진입 후 뷰어(도서 읽기) 실행/종료 또는 시리즈 스캔/메타데이터 적용 등으로 인해 상세 뷰가 재로드(`openBookDetail`)될 때, 기존 목록의 스크롤 위치(`state.scrollPositions`)가 0px로 덮어씌워져 최종 뒤로가기 시 카테고리/대시보드 상단(0px)으로 복귀하는 버그를 해결합니다.

### 주요 원인
- `modal.js`의 `openBookDetail()` 함수가 호출될 때마다 현재 스크롤 위치를 무조건 다시 캡처하여 `state.scrollPositions`에 저장함.
- 상세 뷰가 이미 열려있는 상태에서 뷰어 닫기 후 재로드 시 스크롤 위치(0px)가 캡처되어 이전 목록의 스크롤 위치(예: 1500px)가 오염/파괴됨.

---

## 2. 작업 목표 및 단계별 수행 계획

- [ ] **1단계: 상세 뷰 렌더링 스크롤 위치 보호 로직 구현 (`static/js/modal.js`)**
  - `openBookDetail()` 최초 호출(목록 ➔ 상세 뷰 진입) 시에만 `state.scrollPositions`를 캡처하도록 수정.
  - 이미 상세 뷰가 활성화된 상태에서 재로드 시 기존 목록 스크롤 위치 보존.
- [ ] **2단계: 검증 및 문서화**
  - 상세페이지 ➔ 뷰어 읽기 ➔ 뷰어 닫기 ➔ 목록 뒤로가기 시 이전 스크롤 위치 복원 동작 검증.
  - `./docs/bug/20260723_bugfix_detail_refresh_scroll_position_loss.md` 문서 작성.
  - `./tools/collect_docs.py` 전역 문서 집계 도구 실행.
