Project Gutenberg

저작권이 만료된 고전 도서를 무료로 제공하는 gutenberg.org를 앱 안에서 열람하고, 원하는 책을 라이브러리로 바로 다운로드해볼 수 있는 데모 플러그인입니다.

이 플러그인은 gutenberg.org를 기본 제공/추천하지 않습니다. 아래 기능을 쓰려면 먼저 설정 > 외부 도메인 탭에서 gutenberg.org(또는 *.gutenberg.org)를 직접 등록해야 합니다. 등록/이용에 대한 책임은 사용자 본인에게 있습니다.
